# MlynyHub – Social Network for Mlynská Dolina

MlynyHub is a social network designed for students and residents of **Mlynská Dolina in Bratislava**. It allows users to **create and manage events, register and log in, and interact with the community.**

## Features
- **Event Creation** – Organize and manage local events.
- **User Authentication** – Secure login and registration with Firebase Authentication.
- **Event Management** – View, edit, and delete your events.
- **Community Interaction** – Invite friends and share events.
- **Notifications** – Stay updated on upcoming events.
- **Modern UI** – Intuitive design optimized for iOS.

## Technologies Used
- **Swift (UIKit)**
- **Firebase (Auth, Firestore, Storage)**
- **UIKit and AutoLayout**
- **MapKit (for event locations)**
- **REST API Integrations**
- **Cloud Firestore (real-time database)**
